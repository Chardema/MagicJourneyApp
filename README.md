# MagicJourneyApp

This project is a React Native application built with Expo. It includes various screens for planning a trip and viewing park information.

## Countdown

The app displays a countdown to the start date of a trip directly within `HomeScreen.js`. The previous standalone `CountdownTimer` component was unused and has been removed.

## Development

Install dependencies and run the Expo dev client:

```bash
npm install
npm start
```

## Project Structure

- `screens/` – React Native screens such as `HomeScreen.js`.
- `components/` – Reusable UI components.
- `redux/` – Redux actions and reducers.
